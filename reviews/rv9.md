## PR 18 — parity/18-decks

Range `ba8a091` (origin/parity/09-refactor-decks) .. `a7b9684` (origin/parity/18-decks): 19 commits, 136 files, +6338/−479. Desktop reference: Cockatrice `add65caa` at /tmp/cockatrice. Paths below are relative to `packages/` unless they start with `servatrice/`, `cockatrice/` or `libcockatrice_*` (those are in the desktop tree).

### Headline
- **What's good.**
  - `deckUpdate` finally gives the remote save a proper Sockatrice → Datatrice path. A proto2 presence spec pins that `path` stays unset on the wire. The raw `Command_DeckUpload` hack in the UI is gone.
  - Autosave now uploads only when the deck changed.
  - Every new string is in a co-located `*.i18n.json`, and `i18n-default.json` matches the merged files exactly (checked by script: 0 missing, 0 differing, 0 extra keys).
  - The layering is clean: features → feature-widgets/shortcuts, with no UI dispatch of server state.
- **Blocker.** Move deck is built from upload + delete, and the response matching is unsafe. A failed upload is never cleared, because `DECK_UPLOAD_FAILED` is not handled. The PR notes say Sockatrice has no such failure callback, which is false. An unmatched later upload answer then falls back to the oldest pending entry, so a deck can be deleted although its copy was never created.
- **Majors.**
  - `deckUpdate` cannot send `color_identity`, which desktop's `actSaveDeck` sends. Servatrice overwrites that column on every update, so every web autosave blanks a deck's color identity on 3.1 servers.
  - Move also drops the deck's public visibility and breaks share links, because the deck gets a new id.
  - The Spellbook change (main deck + commanders only) did not update the bracket fingerprint. Moving a combo piece to the sideboard keeps a stale cached bracket.
  - GAME-006 is claimed closed, but `<playmatCard>` is still dropped on every save.
- **Per-feature parity.**
  - **Folders**: close to `TabDeckStorage` (New folder: `/` becomes `-`, 255-character limit; delete confirms its scope; download). The web-only "move" is unsafe → **not ready**.
  - **Undo/redo**: faithful port of `DeckListHistoryManager` (restoreAndSwap, reason strings, 300/400 ms coalescing, Ctrl+Z/Y/Shift+Z, jumps from the history list) → **parity**.
  - **Legality**: faithful port of `isCardQuantityLegalForFormat`, including exceptions. The deviations (unknown vs illegal, `unlimited` legal) are justified and documented → **parity with minor gaps**.
  - **Banner + tags**: the `providerId` round trip and desktop's default tags are correct. Storage-view editing and playmat are missing → **Partial; GAME-006 should stay Partial**.
  - **Sample hand**: matches the desktop widget (default size 7, minimum 1, main deck only, redraw) → **parity**.
  - **Online services**: URLs and forms match desktop (`deck_link_to_api_transformer.cpp` patterns, `exportDeckToDecklist`, deckstats/TappedOut forms). Loading is a documented copy/paste hand-off → **acceptable**.
