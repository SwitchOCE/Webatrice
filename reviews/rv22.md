## Checked and fine
- **i18n:**
  - `features/decks` is off PR 28's off-list (`eslint.config.mjs:110`), and lint covers it with 0 hits.
  - Plurals are real ICU plurals (`{count, plural, …}`).
  - Card names, set names and Scryfall syntax are passed as values, never translated. Examples: `Trans values={{ name }}`, `SYNTAX_EXAMPLES`, `bracketData` card lists.
  - The four deliberate literals (default tags, export headers, `Unnamed deck`, `Deck #N`) match the audit.
  - A grep for leftover English literals in non-spec `.ts`/`.tsx` found only `console.error` text and Scryfall card names.
  - Every dynamic key family resolves: `DeckEditor.section.*` (all 11 `DECK_SECTION_ORDER` values), `CardSearch.color|cardType|rarity.*`, `Decks.list.age|view.*`, `ExportDeckDialog.format.*`.
  - `Intl.RelativeTimeFormat` narrow still gives "3h ago" in English (ICU 77).
- **D1, deck dialogs.**
  - Create and Import take focus into their field, and 15 Tabs never leave the dialog.
  - Escape closes and focus returns to the opener.
  - Delete deck is an `alertdialog` with a name and a description. Focus lands on Cancel, and Escape returns focus to the row's Delete button.
- **D2, share dialog.**
  - Focus starts on the name field. After Enter, focus moves to the link field with the whole link selected.
  - There is exactly one `role=status`.
  - Escape returns focus to "Share deck…".
- **D3, quick add.**
  - The field is a named `combobox` with `aria-expanded`, `aria-controls` and `aria-activedescendant`.
  - The status reads "1 suggestion", and the first Escape closes the list.
- **D4, row menu.**
  - Shift+F10 opens "Actions for {card}" with focus on the first item. End, Enter and Escape work, and focus returns to the row.
  - Removing the row from the menu hands focus to its neighbour.
  - "Move to sideboard" on a commander uses `aria-disabled` with a reason.
- **D6, deck grid.**
  - The whole deck is one tab stop.
  - Home and End work, and ↑/↓ cross from Land into Sideboard.
  - Enter, Ctrl+Alt+= and NumpadAdd add a copy; Shift+← removes one.
  - After Shift+S, focus follows the row into Sideboard.
  - Ctrl+O on My Decks opens Import.
  - Ctrl+N from the editor (headless) lands on My Decks with Create open.
  - Ctrl+S saves.
- **Shortcut scopes, no collisions.**
  - `DECK_EDITOR` and `GAME` are mutually exclusive route scopes (`computeRouteScope`), and no `GLOBAL` bindings exist. So `deck.save` Ctrl+S and `game.shuffleLibrary` Ctrl+S, or `deck.redo` Ctrl+Y and `game.playTop` Ctrl+Y, never meet.
  - The row-local keys (Enter, Delete, Shift+←/→, Ctrl+Alt+=/−, Shift+S) match no `DECK_EDITOR` default.
  - `isModalOpen` stands deck shortcuts down inside dialogs, and the text-input guard keeps `=` and `−` typeable in quick add.
- **Layering.** No server state is dispatched from the UI. Saves go through the existing autosave and `useDeckSharing` paths.
