Settings gains desktop's General, Appearance and Storage options. Appearance now offers a Light, Dark or System palette that switches live and follows the operating system in System mode; existing users keep the dark palette. Every shipped translation (12 languages) can be chosen in General › Language or on the login page, and browsers reporting a regional language such as `pt-BR` now reach its catalogue. The Storage section shows browser storage usage and per-table counts, requests persistent storage, and clears the Scryfall cache or the imported card database without touching settings, shortcuts or servers. A "View debug log" dialog, reachable from the user menu and Settings › General, shows recent client messages with passwords redacted, and can copy or clear them.
