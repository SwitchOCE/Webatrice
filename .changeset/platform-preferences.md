Five more desktop settings. General › Startup tab chooses where a fresh login lands: Deck Storage, Game Replays, the server lobby (the default, as before) or a Server Room opened by name, optionally only on one server; reloading the page still returns to the page you were on. General › Version can tell you, once per server, when the server supports features this Webatrice does not. Chat › Enable mention completer suggests names as you type `@` in room, private and game chat, chosen with the arrow keys and inserted with Enter or Tab. User Interface › Replay sets the buffer time that merges quick backward skips into one rewind. User Interface › Open deck in new tab by default gives each deck its own tab instead of reusing the one you have open.
