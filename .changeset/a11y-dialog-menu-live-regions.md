Keyboard and screen-reader fixes across the platform screens. Dialogs now take focus when they open, keep Tab inside, close on Escape, and return focus to the control that opened them. The game filter and shortcut-recording dialogs now share that behaviour. The user context menu (private chat, buddy and ignore lists, report, every moderator action, and "Show games") opens from the keyboard with Shift+F10 or the Menu key on a user's name. It and the user menu in the top bar are now real menus: arrow keys, Home and End move between items, a typed letter jumps to an item, Escape closes the menu, and focus goes back to where it was. Toasts are announced reliably. Their countdown pauses while the pointer or focus is on them, and toasts that lead somewhere, such as an incoming private message, stay until dismissed. Screen readers now read room and private chat as they arrive and announce connection changes in the top bar. Form errors are attached to their fields. The page language follows the chosen UI language, and the browser tab names the current page. Primary buttons and form-field borders now meet WCAG contrast in both palettes, and error text uses the theme's danger colour.
