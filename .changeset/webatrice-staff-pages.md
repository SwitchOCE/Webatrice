Staff pages from desktop Cockatrice: Administration, Moderation, Card Art Rules and Developer.

Administration (moderators; server functions for admins only) updates the server message, shuts the server down with a reason and delay, reloads the configuration, grants replay access, force-activates accounts, and has desktop's Lock / Unlock safety toggle. On Cockatrice 3.1 servers, Moderation investigates a user (account info, alts, sessions), lists staff last logins, resets a password (admins; the temporary password is shown once and never stored) and removes an avatar; Card Art Rules lists, adds and removes card-art rules; Developer shows live server statistics to developers. The pages are listed in the user menu for the roles that can use them, and the 3.1 pages stay hidden on older servers.
